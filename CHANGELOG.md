# Changelog

## v0.1.1

- English is the default when no language preference has been saved. Existing language choices are preserved, and European Portuguese is available in **Settings → App language**.
- The README now shows how to launch the demo in English and where to change the language or check the installed version.

### Downloads

- **Windows x64.** Extract `SpotifyRS-Windows-x64.zip` and open `spotifyrs.exe`.
- **Linux x86_64.** Run `chmod +x SpotifyRS-Linux-x86_64.AppImage`, then launch it. Add `--appimage-extract-and-run` if FUSE is unavailable.
- **Checksums.** Use `SHA256SUMS.txt` to verify the downloads.
