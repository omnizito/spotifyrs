# Changelog

## v0.1.2

- Click or drag the progress bar to seek in the demo, Soloist, or Spotify Connect when the active device permits it. Hover to preview the time, or focus the bar and use the arrow keys to move five seconds.
- Open **Up next** from the player or sidebar to see the current track and upcoming songs while browsing. The panel follows track and shuffle changes and can be refreshed manually.
- The silent demo now advances to the next track when a song ends, including in shuffle mode.

### Downloads

- **Windows x64.** Extract `SpotifyRS-Windows-x64.zip` and open `spotifyrs.exe`.
- **Linux x86_64.** Make `SpotifyRS-Linux-x86_64.AppImage` executable and launch it.
- **Checksums.** Verify either download with `SHA256SUMS.txt`.

## v0.1.1

- English is the default when no language preference has been saved. Existing language choices are preserved, and European Portuguese is available in **Settings → App language**.
- The README now shows how to launch the demo in English and where to change the language or check the installed version.

### Downloads

- **Windows x64.** Extract `SpotifyRS-Windows-x64.zip` and open `spotifyrs.exe`.
- **Linux x86_64.** Run `chmod +x SpotifyRS-Linux-x86_64.AppImage`, then launch it. Add `--appimage-extract-and-run` if FUSE is unavailable.
- **Checksums.** Use `SHA256SUMS.txt` to verify the downloads.
